# 📊 Sales Analytics Dashboard – Excel

## 📌 Project Overview

This project is an **Excel-based Sales Analytics Dashboard** created to analyze sales performance, customer behavior, product performance, regional sales, and order trends.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Dashboard Design

## 📈 Dashboard Features

- Total Revenue
- Total Quantity Sold
- Total Orders
- Average Order Value
- Total Customers
- Monthly Sales Trend
- Sales by Region
- Profit by Region
- Top 5 Customers by Revenue
- Sales vs Cost by Product
- Sales by Item Category
- Quantity Sold by Product
- Orders Over Time

## 🎛️ Interactive Filters

- Month
- Region
- Item Category

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an **interactive and visually appealing Excel dashboard** that helps users understand sales trends, customer performance, product performance, and regional performance.

## 💡 Key Insights

The dashboard helps identify:

- Overall sales and revenue performance
- Monthly sales trends
- Regional sales performance
- Top customers by revenue
- Product and category performance
- Quantity sold by product
- Order trends over time
